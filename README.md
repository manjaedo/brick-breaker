# 단청 벽돌깨기

단청의 오방색 벽돌을 깨는 브라우저 벽돌깨기 게임입니다. 파일 하나(`index.html`)로 돌아가며 따로 설치할 것이 없습니다.

**플레이:** https://manjaedo.github.io/brick-breaker/

## 조작

- 마우스·손가락 또는 ← → / A D: 받침 이동
- 클릭·탭·스페이스: 공 발사
- P / Esc: 일시정지

## 특징

- 스테이지 5개 (첫 담장, 탑, 격자, 문살, 꽃살). 다 깨면 처음으로 돌아가고 공이 빨라집니다.
- 금테 철벽돌은 두 번 맞아야 깨집니다.
- 아이템: 넓(받침 넓게), 셋(공 셋으로), 느(공 느리게), ♥(목숨 +1)
- 평조 5음계로 만든 배경음악과 효과음 (Web Audio로 직접 합성)
- 최고 점수는 브라우저에 저장됩니다.

# 단청 벽돌깨기

단청의 오방색 벽돌을 깨는 브라우저 벽돌깨기 게임입니다. 파일 하나(`index.html`)로 돌아가며 따로 설치할 것이 없습니다.

**플레이:** https://manjaedo.github.io/brick-breaker/

## 조작

- 마우스 또는 ← → / A D: 받침 이동
- 모바일: 화면 아무 곳이나 좌우로 밀어서 이동, 탭해서 발사
- 클릭·스페이스: 공 발사
- P / Esc: 일시정지

## 특징

- 직접 만든 스테이지 20개 (첫 담장, 탑, 격자, 문살, 꽃살, 계단, … 마지막 단청). 21스테이지부터는 좌우대칭 무늬가 끝없이 새로 만들어집니다.
- 금테 철벽돌은 두 번, 금테가 두 겹인 겹철벽돌은 세 번 맞아야 깨집니다.
- 아이템: 넓(받침 넓게), 셋(공 셋으로), 느(공 느리게), 레(레이저 자동 발사), ♥(목숨 +1)
- 평조 5음계로 만든 배경음악과 효과음 (Web Audio로 직접 합성)
- 배경에 구름(운문)이 흐르고, 학이 날아가고, 소나무가 바람에 흔들립니다. 게임을 가리지 않게 은은하게 그립니다.
- 최고 점수는 브라우저에 저장됩니다.
- 모바일 최적화: 세로 화면에 맞춰 판이 늘어나고, 홈 화면에 추가하면 전체 화면으로 실행됩니다.
